# Cappy Hub

Cappy Hub is the internal administrative application for the **Coding Interview Club (CIC)**. It helps officers manage officers, events, participation, points, warnings, and administrative activity.

The application uses Next.js, React, TypeScript, Supabase, PostgreSQL, Tailwind CSS, and Vitest. The project is maintained by CIC members and is intended to stay understandable for future officers.
