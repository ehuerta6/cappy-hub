# Useful Commands

```bash
# Full local app environment
npm run local:start
npm run local:reset
npm run local:stop
npm run dev

# Formatting
npm run format
npm run format:check

# Code quality
npm run lint
npm run typecheck

# Tests and production build
npm test
npm run build

# Database-only test stack
npm run db:start
npm run db:reset

# Generated database types
npm run db:types
npm run db:types:check
```
