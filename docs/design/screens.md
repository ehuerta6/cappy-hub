# Screen guidance

## Page composition

- **Dashboard:** Match the Events and Tasks page header. Summarize current counts and activity; keep action items (with inline **Mark complete** / **Awaiting approval** controls for assigned Tasks), the Lead/Admin **Needs your review** queue, upcoming Events, and recent point activity easy to scan.
- **Events and Tasks:** Keep page headers, quick views, horizontal filter bars with removable active filter chips, relative date cues (including the live dot on happening Events), section headings, list density, tags, and action placement aligned. Quick views use compact underlined links with a clear selected state; keep them distinct from the grouped search/filter form. Their compact row actions share the same button geometry and blue primary treatment. Task assignment progress shows a concise completed count and compact meter for active assignments, “All completed” when the active roster is complete, and a clear unassigned state without an empty meter. Event participation keeps Volunteer and Attend visible as choices, labels the selected signup as “Signed up” or “Attending,” and uses color only as a reinforcing selected state. Their create/edit pages share the same form composition, including resource-link quick-add presets and `SearchableOfficerChecklist` with select-by-branch chips; Event Time Slots show 12-hour labels and point previews.
- **Event and Task details:** Use the shared `ContextualBackLink`, `PageHeader`, `CopyButton`, flattened single-page sections (no in-page sub-tabs or detail pagination), status treatment, and contextual return behavior. Event details include roster search/filtering, copy-emails, **Duplicate event**, and **Create linked task** shortcuts; Task details include a completion summary and **Approve all pending** when multiple completion reports await review.
- **Calendar:** Provide `All club`, `My schedule`, and `My branch`/`My branches` quick views, a **Month / Agenda** layout switcher with live Event/Task counts, Event/Task visibility checkboxes, and quick create links when authorized. The default date follows the current or explicitly selected period rules above.
- **Officers:** Use a cards-only directory (no avatars) with `All officers` and `3+ warnings` tabs, horizontal filters, and inline email `Copy` buttons. Officer detail profiles are flattened (no in-page sub-tabs or detail pagination) with `mailto:`/copy email controls and activity stats. Warning forms include a live threshold preview and starter reason chips. Officer role and branch controls follow the existing authorization rules.
- **Points:** Keep Overview and History tabs consistent with the app. Overview provides instant leaderboard filtering, top-3 rank accents, and a quick jump to the signed-in Officer's rank. History displays filtered transaction counts and filtered net points alongside uniform `Edit points` and `Remove` (`button-danger`) controls, without adding workflows or changing award semantics.
- **Notifications:** Keep the header bell preview and full inbox aligned with read/unread toggles, **Mark all as read**, and a **Needs attention only** filter toggle in the full inbox.
- **Admin:** Keep landing, period, catalog, and embedded warning workflows within the same page headers, back links, forms, tables, dialogs, tabs, and action hierarchy. Academic period creation includes **Quick fill** semester presets (`Spring`, `Summer`, `Fall`) and a live duration preview. Catalog `Add`/`Save` actions use primary filled buttons; Branch, Event Type, and Task Type catalog colors use a compact popover with named swatches, native custom color selection, HEX (`var(--font-geist-mono)`) and RGB inputs, and a live tag preview whose placement stays within the viewport. Their tags use the shared status-badge shape, with theme-aware text and surface contrast.
- **Login and recovery:** Keep these focused on product identity, a clear explanation, and the existing sign-in or recovery action. Do not turn them into marketing pages.

When an action is absent for a role or historical period, recompose the page so its remaining content uses the space well.
