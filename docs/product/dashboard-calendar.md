# Dashboard and internal Calendar

## Dashboard and internal Calendar

### Dashboard — current / shipped

The current-period Dashboard retains the current summary and personal action surface: signed-in Officer name and Position, personal lifetime Point total/profile link, active Officer count, upcoming Event count, current-period net Points, up to five eligible personal action items, up to five eligible upcoming Events, and the latest five active Point transactions. Personal action items contain incomplete assigned Tasks ordered by due date and ID. Warning decisions are no longer prompted on the Dashboard. Upcoming Events are ordered by start time and ID and show signup state and signup counts. Recent Point transactions are ordered newest first by creation time and ID. Each preview may contain fewer than five items when fewer eligible records exist. The summaries derive from domain records; they are not separately maintained data or new workflows.

For a selected past or future academic period, the Dashboard shows that period's active Event count, active Task count, net Points, and ranking. Past-period views are read-only. A date gap shows “No current period” and keeps the normal unfiltered workflows available.

### Calendar — current / shipped

The internal Calendar is a read-only combined view of non-cancelled, non-removed Event occurrences and non-removed Task due dates from their source records. A selected academic period filters Events by Event date and Tasks by due date. Selecting an item opens its canonical Event or Task. Display filters change only what is shown. Calendar is not a second source of scheduling truth and does not synchronize to Google Calendar.
